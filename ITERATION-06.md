# Iteration 06 — Prototype Reset

This iteration intentionally removes the ornate guidebook treatment and returns Eolas to a simple, usable companion format.

What is playable:
- Reliable light/dark and regional themes
- Quick navigation
- Region checklist and contextual region notes
- Searchable starter Paldex records with notes per Pal
- Base location tracker with notes per base
- General quick notes
- Local persistence
- Offline shell

The included Pal records are a small prototype dataset, not a complete production Paldex.
